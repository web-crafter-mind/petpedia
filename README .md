# PetPedia 🐾
**PetPedia** is a comprehensive, interactive web application designed as an all-in-one educational resource for pet owners and animal enthusiasts. Built with a modern, responsive interface, it provides the tools and knowledge needed to care for dogs, cats, birds, fish, rabbits, and reptiles.

## 🚀 Live Demo
You can view the live project here:
[https://umarhabib35102-lang.github.io/petpedia/](https://umarhabib35102-lang.github.io/petpedia/)

## ✨ Key Features
* **Comprehensive Pet Guides:** Detailed care sheets for 60+ species, covering health, training, and breed-specific info.
* **Interactive Care Tools:**
    * **Pet Care Calculator:** Estimate monthly food costs, time requirements, and exercise needs.
    * **Habit Tracker:** Build consistency in pet care routines.
    * **Pet Name Generator:** Find the perfect name for your new friend.
* **Educational Resources:**
    * **Knowledge Flashcards:** Quick facts for rapid learning.
    * **Pet Care Master Quiz:** Test your knowledge and track your progress.
    * **Study Planner:** Organize your learning journey.
* **Resource Library:** A built-in shop interface for professional PDF care guides.

## 🛠️ Tech Stack
* **Frontend:** HTML5, JavaScript
* **Styling:** [Tailwind CSS 4](https://tailwindcss.com/) (via CDN)
* **Icons:** [Font Awesome](https://fontawesome.com/)
* **Typography:** Google Fonts (Poppins)
